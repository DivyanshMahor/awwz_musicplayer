# 🎵 AwwZ Music Player

> **My personal music player, built because I genuinely love listening to music.**

AwwZ is a personal offline music player built with **Flutter**.

I created this project primarily for myself. I listen to music almost every day, so instead of building another random practice application, I wanted to create something that I could actually use in my daily life.

The goal is simple:

**Open AwwZ. Pick a song. Press play. Enjoy the music. 🎧**

## ❤️ Why I Built AwwZ

This project is a little different from my other projects.

AwwZ is one of my favourite projects because it comes from something I personally enjoy.

I love listening to music, especially when I am coding, travelling, studying, or just relaxing. I wanted a music player that felt simple, clean, personal, and focused on the actual listening experience.

This project is also part of my journey of becoming a better Flutter developer.

Instead of only building projects to put on a resume, I wanted to build something that I would actually keep using.

## 🚀 Getting Started

### Requirements

Make sure you have Flutter installed on your system.

You can check your Flutter installation using:

```bash
flutter doctor
```

### Clone the repository

```bash
git clone https://github.com/DivyanshMahor/awwz_musicplayer.git
```

### Open the project

```bash
cd awwz_musicplayer
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```

The main goal of AwwZ is not to compete with Spotify or other large music platforms.

It is much simpler than that.

I want to build a music player that belongs to me, works the way I want, and gives me a distraction free place to listen to my own music.
